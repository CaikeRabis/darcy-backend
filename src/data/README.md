# Snapshot CNPq

`cnpqCatalogSnapshot.ts` é uma transcrição UTF-8 do CSV oficial `Tabela de Áreas do Conhecimento`, publicado pelo Conselho Nacional de Desenvolvimento Científico e Tecnológico (CNPq) no diretório de dados abertos.

- Origem: `https://memoria.cnpq.br/documents/guest/dados%20abertos/TabeladeAreasdoConhecimento.csv`
- Publicação indicada pelo diretório: 25 de abril de 2013
- Versão interna: `cnpq-tac-2013-04-25`
- Atribuição exigida no produto e na documentação: Conselho Nacional de Desenvolvimento Científico e Tecnológico (CNPq).

O CNPq apresenta o material como dado aberto; a política federal de dados abertos prevê uso, reutilização e cruzamento de dados públicos em formato aberto. O snapshot não deve ser atualizado automaticamente em runtime. Qualquer atualização exige revisão humana da fonte, da data de publicação, do checksum, da atribuição e dos termos oficiais então vigentes.
